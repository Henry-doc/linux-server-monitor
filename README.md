# Linux Server Health Monitor

A Bash script that monitors the health and resource usage of a Linux server.

## Features

- Displays server hostname and uptime
- Monitors memory usage
- Monitors disk usage
- Monitors CPU usage
- Displays top CPU-consuming processes
- Generates warnings when resource usage exceeds 80%

## Technologies Used

- Linux
- Bash
- Git
- GitHub
- awk
- bc

## How to Run

Make the script executable:

chmod +x server-health.sh

Run the script:

./server-health.sh
